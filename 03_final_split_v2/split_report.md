# 验证集划分报告（最终冻结 v2）

> 最终复核日期：2026-09-02 · 训练 : 验证 = 80 : 20  
> 输出文件：`splits/train_ids.csv`、`splits/valid_ids.csv`

## 1. 结论

最终划分覆盖全部 12,568 张训练图片：训练集 10,054 张，验证集 2,514 张。两个集合无交集、无重复 ID、无遗漏、无未知图片 ID。

初始 v1 使用图片级标签组合分层，类别比例良好，但最终复核发现 19 条跨训练/验证的强感知近重复边，涉及 18 个跨集合近重复组。v2 将这些近重复组约束在同一集合，并使用相同标签组合、掩码面积尽量接近的安全样本进行一对一置换。因此训练/验证数量和每种标签组合的计数均保持不变，强跨集合近重复边从 19 降为 0。

## 2. 数据范围与标签口径

- 原始数据：`D:/kagllee/dataset`
- 抽样单元：图片，而不是标注行。
- 无缺陷图片：不在 `train.csv` 中的 5,902 张训练图片，组合记为 `none`。
- 正标签：仅使用 Kaggle 给出的匿名数字类别 `class_1`～`class_4`，不赋予未经官方确认的缺陷名称。
- 同一张图片可以同时属于多个正类别。

## 3. v1 分层策略

v1 使用 `random_state=42`、`test_size=0.2`，按图片级精确标签组合分层。样本少于 30 的 `(2,3)`、`(1,2,3)`、`(2,4)` 合并为一个稀有层，以避免单样本组合无法直接分层。

## 4. v2 近重复约束

### 4.1 检测方法

对全部 12,568 张训练图计算 64 位感知哈希（pHash），先筛选汉明距离不大于 4 的候选，再在 256×64 灰度缩略图上计算归一化平均绝对差和相关系数。

强近重复判定规则：

```text
pHash Hamming distance <= 4
normalized MAE <= 0.03
correlation >= 0.98
```

该规则用于识别非常相似的图像，不等价于钢卷或生产批次 ID。由于原始数据没有提供组别元数据，无法保证检出全部业务层面的关联样本。

### 4.2 修正结果

| 检查项 | v1 | v2 |
| --- | ---: | ---: |
| 强跨集合近重复边 | 19 | 0 |
| 跨集合近重复组 | 18 | 0 |
| 训练图片 | 10,054 | 10,054 |
| 验证图片 | 2,514 | 2,514 |
| 标签组合计数是否保持 | — | 是 |

处理方式：将 18 张近重复验证图移入训练集，再从训练集中选择 18 张不属于任何强近重复边、标签组合相同且掩码面积尽量接近的图片移入验证集。v1 仅由交接人本地留档，不随本包分发；后续实验统一使用 v2。

## 8. 使用方式

划分 CSV 每行一个图片 ID，**没有表头**。Pandas 应按以下方式读取：

```python
train_ids = pd.read_csv("train_ids.csv", header=None, names=["ImageId"])
valid_ids = pd.read_csv("valid_ids.csv", header=None, names=["ImageId"])
```

无缺陷图片在训练和验证时应使用四通道全零掩码。
